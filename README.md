# Around The Wereld

Named after the iconic Daft Punk track, **Around The Wereld** is a custom WordPress theme developed for **Wereldcafé**, a multicultural restaurant and social venue based in Leuven, Belgium.

The theme was designed to provide a flexible and intuitive content management experience while delivering a modern, responsive, and performant front-end for visitors.

## Features

* Custom WordPress theme built from scratch
* Advanced Custom Fields (ACF) integration
* Flexible content management for non-technical users
* Responsive design for mobile, tablet, and desktop
* Custom page templates
* Reusable content components
* Optimized asset loading
* SEO-friendly markup
* Accessibility-conscious implementation

## Technologies

* WordPress
* PHP
* Advanced Custom Fields (ACF)
* JavaScript
* CSS
* HTML5

## Project Goals

The primary objective of this theme was to create a maintainable and scalable website tailored to Wereldcafé's needs, allowing staff members to easily update menus, events, content sections, and promotional information without requiring technical knowledge.

## Development

### Requirements

* WordPress 6.x
* PHP 8.x
* Advanced Custom Fields Pro

### Installation

1. Clone the repository into the WordPress themes directory.
2. Activate the theme from the WordPress administration panel.
3. Install and activate the required ACF plugin.
4. Import the field groups if necessary.
5. Configure theme options and content.
